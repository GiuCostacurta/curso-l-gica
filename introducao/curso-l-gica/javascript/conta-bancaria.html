conta bancária

criar uma classe ContaBancaria que tenha uma propriedade privada para o saldo.

utilizar getters e setters para acessar e atualizar o saldo. o saldo só pode ser atualizado através de depósitos e saques, e não deve permitir que o saldo se torne negativo.

implementar métodos para depósito (depositar(valor)) e saque (sacar(valor)), onde o saque só é permitido se houver saldo suficiente.
